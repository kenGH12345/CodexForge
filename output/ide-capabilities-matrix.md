## 5. 关键发现速览

### ✅ 优势 (Strengths)

1. **Symbol Lookup**: 完美的 IDE-First 路由，优先 `view_code_item`
2. **LSP Adapter 跳过**: 检测到 IDE 时正确跳过自启动 LSP
3. **独有能力**: Hotspot、Module Summary、Project Profile 等 IDE 无对应能力
4. **架构清晰**: 7 阶段流水线与 IDE 能力分层明确

### ⚠️ 弱点 (Weaknesses)

1. **Call Hierarchy**: 100% 依赖 CodeGraph regex，未利用 IDE LSP
2. **路由分散**: 各模块自行判断 IDE vs 自建，缺乏中央调度
3. **Claude Code**: 无 LSP 但需要特殊处理，部分功能受限

### 🔥 机会 (Opportunities)

1. **MCP 整合**: 随着 MCP 普及，可统一封装 LSPAdapter 为 MCP Server
2. **Call Hierarchy**: 实施后可立即提升 30% 业务逻辑分析准确率
3. **混合策略**: 对 IDE 质量不高的能力，设计智能 fallback

### ⚡ 威胁 (Threats)

1. **IDE 能力增强**: Cursor/VS Code 持续增强，需持续跟进对比
2. **MCP 生态竞争**: 如 IDE 原生 MCP 能力强于自建模块，需重新评估定位
